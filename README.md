# 🌸 JeniStock – Sistema de Controle de Estoque de Perfumes

## 📌 Sobre o projeto

O **JeniStock** é um sistema desenvolvido para facilitar o gerenciamento e o controle de estoque de perfumes. O objetivo é organizar os produtos, acompanhar as quantidades disponíveis e tornar o controle de entradas e saídas mais simples e eficiente.

## 🎯 Objetivo

Desenvolver um aplicativo prático e organizado para administrar o estoque de perfumes, evitando perdas de produtos e facilitando o acompanhamento das mercadorias.

## ⚙️ Funcionalidades

- Cadastro de perfumes.
- Listagem de produtos cadastrados.
- Edição das informações dos perfumes.
- Exclusão de produtos.
- Controle de entrada e saída de estoque.
- Consulta de quantidades disponíveis.
- Pesquisa de perfumes pelo nome.
- Controle de preços dos produtos.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- React
- Banco de Dados

## 📦 Organização do estoque

Cada perfume poderá conter as seguintes informações:

- Nome do perfume.
- Marca.
- Categoria.
- Quantidade disponível.
- Preço de compra.
- Preço de venda.
- Descrição do produto.

## 🚀 Benefícios

O JeniStock proporciona mais organização, agilidade e praticidade no gerenciamento de perfumes, ajudando a controlar os produtos e melhorar a administração do estoque.
